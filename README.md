# 📷 Projeto: Inserindo Imagens em HTML

Este projeto é um exemplo básico de como **inserir imagens** e **links externos** em uma página HTML utilizando as tags `<img>` e `<a>`.

## 📝 Descrição

O código demonstra:
- Como usar a tag `<img>` para inserir imagens em uma página.
- Atributos importantes da tag `<img>`:
  - `src` → define o caminho da imagem.
  - `alt` → texto alternativo (usado quando a imagem não carrega).
  - `width` e `height` → controlam as dimensões da imagem.
- Como usar a tag `<a>` para criar **links clicáveis** que abrem em uma nova aba com o atributo `target="_blank"`.

## 📂 Estrutura do Projeto

projeto-inserindo-imagens/
│── index.html # Código principal
│── img/
│ └── download.png # Imagem usada no exemplo


## 🚀 Como executar

1. Faça o download ou clone este repositório.
2. Abra o arquivo `index.html` em qualquer navegador.
3. A página exibirá:
   - Um título explicativo.
   - Uma imagem centralizada.
   - Links que redirecionam para **Google** e **YouTube**.
